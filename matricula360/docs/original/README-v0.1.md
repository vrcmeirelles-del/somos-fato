# Matrícula 360° v0.1 — fundação para desenvolvedor
Node 22+, sem dependências externas. `npm test` e `npm start`, abra http://127.0.0.1:4173. A página pública e a demonstração usam HTML/CSS/JS; dados fictícios em memória, sem login. Não use dados reais nem exponha o servidor à internet. `src/motor.mjs` contém regras puras, `test/` testes, `db/schema-proposto.sql` rascunho de banco somente leitura sob RLS (não executado). `INSTRUCOES-DESENVOLVEDOR.md` é o roteiro para construção do produto completo. `BIBLIA-MESTRA.md` contém requisitos e limites. Não foram criados serviços remotos. Documentação RLS: https://supabase.com/docs/guides/database/postgres/row-level-security.
